# SpendWise - Budget Tracker

## Project Overview
SpendWise is a responsive web application designed to help users track and manage their day-to-day personal expenses. This project is built as part of the Power Learn Project (PLP) web development curriculum.

## Features & Structure
- **HTML Table (`index.html`)**: Displays 5 rows of sample expenses categorized clearly with headers (`<thead>` and `<tbody>`).
- **Form Upgrade**: An interactive form equipped with explicit input IDs and a categorized `<select>` drop-down list (`Food`, `Transport`, `Rent`, `Entertainment`, `Other`).
- **Multimedia Integration**: Features a logo icon (`<img>`) and an embedded budgeting guide video (`<iframe>`).
- **Interactive Elements**: Includes a collapsible summary section (`<details>`), custom row hover feedback, and tailored button cursor styles.
- **Advanced CSS Selectors (`style.css`)**: Implements descendant selectors, direct child selectors, position-based pseudo-classes (`:first-child`, `:nth-child`), negation pseudo-classes (`:not()`), and dynamic focus highlights.

## How to View
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
